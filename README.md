# Netflix-Analysis---Power-Bi
Created an interactive Netflix Data Analysis Dashboard in Power BI using the given datasets. Applied multiple DAX measures, calculated columns, slicers, bookmarks, and visualizations to analyze content, watch time, ratings, customers, subscriptions, genres, and viewer engagement.
